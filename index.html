Le chiffre de César

Chaque lettre avance de quelques rangs dans l'alphabet. Choisissez une clé, écrivez : le message se transforme sous vos yeux.

Casser le code

Vingt-cinq clés seulement : il suffit de toutes les essayer. La plus vraisemblable est repérée par la fréquence des lettres en français.

Écrivez un message pour voir ses 25 déchiffrements possibles.
